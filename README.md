# rochaOS

> Terminal-style interactive portfolio — [rochaluis.com](https://rochaluis.com)

---

A browser-based portfolio built to look and feel like a Unix terminal. Type commands, navigate sections, read about projects and experience.

Built with vanilla HTML, CSS, and JavaScript — no framework, no build step. Served via nginx on a self-hosted homelab.
